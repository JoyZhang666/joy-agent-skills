## 开始或恢复工作

确认工作区根目录 → 读取规则 → 从索引进入项目 → 阅读 README、project.json、STATUS → 按登记找到输入和当前文件 → 执行与验证 → 更新交接记录。

## 新建项目

选择稳定 project-id，在 `01_projects/<project-id>` 建立四份基础文件。各阶段按需建立并登记；先生成索引，再运行检查。不要把模板占位内容当作项目事实。
