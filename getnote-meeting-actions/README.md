# Get 会议行动 · v2.0.0

**会议与执行 · Get 授权 · 默认本地保存**

| 你提供什么 | 得到什么 |
|---|---|
| 你选定的 Get 会议原文，以及希望处理的范围。 | 带原文依据和稳定编号的行动清单；获授权执行后保存本地成果与续接记录。 |

**先准备：**可读取授权会议原文的 Get 官方 CLI 与 Agent；辅助脚本需要 Python 3.10+。上传 Get 需另行授权。

## 开始使用

安装为个人技能后，在新 Codex 任务中说：

> 使用 $getnote-meeting-actions，处理我指定的 Get 会议笔记，先列有原文依据的待办。

选定笔记后可回复“1、3 你来做”。清单、记录和成果默认仅本地保存，不上传 Get。续接时说“继续上次会议，2 我已经完成了”，会优先读取当前项目已有记录，复用已完成成果。

确需上传时明确说“把这份清单/本批成果存到 Get 的 X 知识库”，或同意 Agent 针对具体内容提出的上传申请。已设置知识库、任务完成或曾经上传过都不会自动授权新的上传；没有可明确绑定的上传上下文时，仅说“保存一下”按本地处理。

未安装或平台未自动发现时，让 Agent 显式阅读本目录的 [SKILL.md](SKILL.md)。实际执行需要官方 Get CLI 可用并已由用户完成登录；核心提取和执行由 Agent 完成，辅助 Python 脚本不是独立的 AI 服务。

## 能力边界

能完成调研、文稿、阅读和可发送消息正文。日程生成 `.ics`，任务记录为行动清单；不会声称已邀约、已发送或已创建 Get 原生任务。结果先保存本地；另获明确上传授权后才保存独立 Get 笔记，原会议保留。未上传是正常状态，不影响已完成的本地工作。

CLI 1.5.10 / contract 2.2 已核对；Python 3.10+ 标准库。IANA 时区在 Windows 需要系统或 Python 的时区数据库；若不可用，使用已确认的显式 UTC 偏移，不自动安装依赖。`.ics` 默认使用 UTC 起止时间。

本版没有后台自动发现、云服务、视频下载或自动对外分享会议内容的功能。文件与模拟验收不代表已执行真实会议中的任务，也不代表所有宿主与 Get 接口版本均已通过联调。

## v2.0.0 变更（2026-09-21）

默认保存策略从 v1.0.0 的批次成果归档流程改为仅本地保存，因此升级主版本号。案例前移，明确区分任务执行与 Get 上传许可，增加本地/待授权/拒绝状态。旧 profile 缺失策略字段也按本地处理；已保存的历史笔记和回执保留，未完成批次不自动补传。辅助脚本及其 CLI 参数不变；上传许可由 Agent 工作流落实，不宣称存在底层 API 强制拦截。

## 公开包与运行数据

公开包包含通用技能说明、辅助脚本和未填写的配置模板。示例日期、标题与占位值仅用于说明，不对应真实会议或个人身份。

使用时将模板复制到自己的项目运行目录，再填入个人配置。真实笔记、知识库 ID、身份映射、录音、原文、执行成果、保存回执、日志和登录凭证留在各自的运行环境，不写回技能目录，不随公开包分发。GitHub 上传技能与 Skill 运行时上传 Get 是两项独立操作。

本目录的 [.gitignore](.gitignore) 提供常见运行数据的排除规则。排除规则不会清除已经进入 Git 的文件或历史；每次发布前仍应检查全部待提交文件、将推送的历史及下载包。辅助脚本可能在本地生成包含真实会议内容和标识的文件，这些运行产物同样需要保护。
