# 第一次使用 Joy 的 Skill

[← 全部作品](../README.md)

你不必先学会编程。先选一个小任务，让你正在使用的 AI Agent 带着你走完“准备 → 试用 → 核对”的过程。

## 1. 先选一件想完成的事

| 我想做什么 | 从这里开始 | 提前准备 |
|---|---|---|
| 把视频变成文字 | [Youtube 转写全文稿](../youtube-transcript/README.md) | 有权处理的视频链接、本地保存目录；优先尝试已有字幕 |
| 整理会议待办 | [Get 会议行动](../getnote-meeting-actions/README.md) | 自己有权读取的 Get 会议笔记与 Get 授权 |
| 认真读一章书 | [全书精读工作流](../full-book-deep-reading-workflow/README.md) | 有权使用的章节文件与阅读范围 |
| 记录课程余额 | [课程课时台账](../class-hours-ledger/README.md) | 先使用虚构购课、赠课和上课记录 |
| 把资料变得容易交接 | [项目文件管理](../project-file-management/README.md) | 一个测试目录或明确授权的项目目录 |
| 整理 Get 笔记分类 | [GetNote 知识库整理](../getnote-knowledge-manager/README.md) | Get API 凭据、目标知识库与分类规则 |

Linux 代理与 VPS 工具放在[技术工具区](../README.md#技术工具)。它们需要额外环境，建议具备相关基础后再使用。

## 2. 下载完整目录

1. 打开[仓库首页](https://github.com/JoyZhang666/joy-agent-skills)。
2. 点击绿色 **Code** 按钮，再点击 **Download ZIP**。
3. 下载后先解压，找到你选中的项目文件夹，例如 `youtube-transcript`。
4. 保留整个项目文件夹。不要只复制 `SKILL.md`：它可能依赖同目录内的 `scripts`、`references` 或模板。

不必安装 GitHub Windows 客户端。如果你的 Agent 能读取本地文件，可以先把解压后的项目完整路径告诉它。是否能自动发现 Skill、技能应该安装到哪个目录，取决于你使用的 Agent；不要猜路径。

## 3. 让 Agent 先检查准备条件

复制下面这段话，把方括号内的内容换成你自己的信息：

> 请先阅读 [项目完整路径] 中的 README.md 和 SKILL.md。我的目标是 [具体任务]。先说明需要什么输入、依赖和权限，检查哪些已经具备；缺少的条件请逐项指导。输出保存到 [Skill 目录之外的本地目录]。需要付费、把内容交给外部服务或更改现有资料时，先把具体操作说清楚，再等我确认。

如果 Agent 无法读取本地文件、执行所需脚本或调用指定服务，它会停在相应步骤。安装 Skill 不会自动补齐这些能力。项目 README 中的 Python 等要求，可以请 Agent 检查并解释后再安装。

## 4. 如需 API，按对应指南配置

API 可以理解为软件与服务之间的调用入口；API Key 是你访问该服务的凭据。**不是每个项目都需要新的 API Key。**

- **视频全文稿**：已有字幕路线不需要转写 API Key。需要云转写时，按[新手配置教程](../youtube-transcript/references/setup.zh-CN.md)选择服务、申请、配置并完成小样本验证。服务额度与价格以服务商当前页面为准。
- **GetNote 知识库整理**：需要自己的 Get API Key、Client ID 和相应权限，详见[依赖与使用](../getnote-knowledge-manager/README.md#依赖与使用)。Get 会议行动使用 Get 官方 CLI 的授权流程，两者不能混为一谈。
- **课程台账、项目文件管理**：辅助工具不要求外部业务 API；宿主 Agent 本身的账号、模型费用另计。

把密钥留在本机私有配置里。不要放进公开 README、Issue、截图或提交记录；遇到报错时只分享去掉密钥和私人路径的报错内容。

## 5. 先完成一个小样本，再核对结果

先用虚构资料，或你明确有权处理的一小段内容。选择一种检查方式：

- 视频全文稿：打开 `.md` 文件，对照开头、结尾及中间几个位置；若标注中断或待复核，先解决问题。
- 会议行动：每项待办都能回到原文；未明确的负责人、时间保留“待确认”。
- 章节精读：笔记有章节或原文定位，下次阅读能接续进度。
- 课程台账：用“购入 10 + 赠送 2 − 上课 1 = 11”的虚构例子核对余额。

看到“脚本运行结束”还不等于结果正确。确认交付物确实存在、范围正确、能打开，再逐步扩大使用范围。

## 遇到问题怎么描述

可以向 Agent 说明：“我选的是哪个项目、停在第几步、屏幕上的报错、希望得到什么”。公开反馈使用[仓库 Issues](https://github.com/JoyZhang666/joy-agent-skills/issues)，仅附虚构或脱敏示例。
