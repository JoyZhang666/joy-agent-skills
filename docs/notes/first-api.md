# 怎样让第一次配置 API 的人走完最后一步？

“配置 API Key 后运行”对熟悉开发的人很短，对第一次接触的人却省略了最关键的路程。

我希望新手指南回答六个连续的问题：

1. 这次任务真的需要云 API 吗？有不需要额外密钥的路线吗？
2. 选择哪个服务？申请条件、地区限制、额度和费用在哪里查看？
3. 从服务商的哪个官方入口登录、创建密钥？
4. 密钥保存在哪里，怎样避免出现在代码与公开截图中？
5. 如何用一个小样本完成首次调用，确认拿到了实际结果？
6. 余额不足、权限不够或模型不支持时，下一步检查哪里？

**虚构例子：**环境变量存在，只能证明本地保存了一个值。它不能证明密钥有效、账户有额度或转写已经成功。需要一次明确授权的小样本调用，并打开最终文件检查。

因此，Youtube 转写全文稿先介绍已有字幕路线，再说明云转写服务的申请与配置。申请难度、可用额度和价格会变化，最终以服务商当前说明为准。
