# Workflow overview

Contract and scope → accessible source → complete ordered extraction → canonical manifest/state → bounded source reading → evidence-based note → state/index/log → report → next authorized chunk → scope-labelled synthesis.

On failure, retain successful artifacts and record unresolved work. On pause, stop at the requested boundary and persist state. On resume, reconcile source, notes and canonical state before writing. Optional scheduling and external delivery require separately established capabilities and authorization.

See SKILL.md for entry steps and durable-continuity-protocol.md for the single state schema. Use chapter-note.md for interpretation, and validate actual source coverage rather than relying only on counts.
