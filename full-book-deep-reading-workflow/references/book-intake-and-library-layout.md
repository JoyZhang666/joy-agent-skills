# Source intake

Use only the file or folder selected by the user. Do not inspect global caches, home directories or unrelated libraries to discover books. Receiving a file is not approval to read every chapter or copy it into a new library.

Verify format, readability and requested scope. Use the existing source filename; any normalization or relocation requires authorization and a preview. If copying is approved, compare SHA-256 before/after and preserve the original. Choose a project child folder beside the source, using a distinct folder for each book when the source folder contains several books.

Probe PDF text availability on representative pages with an available trusted local tool. Empty text means extraction is incomplete, not that the book has no content. Require accessible text or approved OCR before reading. Do not automatically install OCR or send pages to cloud services.

On shells supporting it, use "$HOME/reading-library" rather than quoted tilde literals for an explicitly chosen example library. Windows users choose an explicit directory in their own environment. No fixed author-specific library layout is assumed.
