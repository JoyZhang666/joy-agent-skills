# Optional tool routing

The workflow does not require external named Skills. Use host capabilities if available:

| Need | Optional capability | If unavailable |
|---|---|---|
| Fiction analysis | Character/plot interpretation | Use chapter template with evidence |
| Nonfiction analysis | Argument/concept analysis | Use chapter template with evidence |
| Large source | Text chunking/indexing | Bounded sequential text reads |
| EPUB/PDF | Trusted local extractor | Request accessible text |
| Scanned pages | Approved OCR | Report blocked extraction |
| Scheduled continuation | Verified host scheduler | In-session/manual resume |
| Slides | User-requested presentation tool | Keep Markdown outline |

Read the installed tool's actual contract before using it. Do not assume tool names, permissions, paths or interfaces from another host. Preprocessing never proves comprehension; interpretation cannot substitute for missing source text.
