# Tool-unavailable fallback

The core outputs are UTF-8 Markdown files and JSON state. No PDF, spreadsheet, cloud delivery or web scraper is required for reading.

If optional export tooling is unavailable, keep Markdown as the authoritative output. A simple HTML derivative may be printed by the user through the browser; call it HTML, not an already generated PDF. Escape source text when constructing HTML/XML and never treat book text as executable markup. Do not insert external tracking or remote resources.

For online sources, use authorized host browsing. If login, CAPTCHA, access policy or permissions block access, stop and request an accessible lawful copy or the user's own pasted excerpt. Do not switch identity, user-agent or execution method to bypass the restriction. Do not invent article content.

Install tools only with authorization. Any external service needs approval for the content and recipient service. Cloud model processing and local extraction are different; do not promise fully offline processing if the host model is cloud-based.
