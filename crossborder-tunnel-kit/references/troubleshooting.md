# 分层定位

| 现象 | 先收集的证据 | 不应直接推出 |
|---|---|---|
| 无法握手 | 实际端口/协议、两端时间、证书链与 SNI、UDP 可达、服务监听、云安全组 | 单一报错就等于 IP 被封 |
| 连接后无网页 | 本地应用是否使用代理、DNS 结果、代理规则命中、VPS 出口、目标站 TLS | 所有流量都已接入 |
| 平台报地区/风险 | 同一应用/账号的受控对照、出口 IP、DNS、HTTP 状态、不同时间复测 | 数据中心 IP 必须换 WARP |
| 速度慢/间歇卡顿 | RTT、丢包、UDP 限速、MTU、VPS 负载、客户端并发、不同目标对照 | 修改一个固定 MTU 就能解决 |
| 国内访问绕远 | 国内规则来源/顺序/命中，客户端是否先解析域名 | 把全部私网或全部中国地址直接放行必然安全 |
| 切换备线仍失败 | 是否同一 VPS/IP/供应商、TCP 是否可达、密钥对与 short-id | 备线提供了独立容灾 |

每次只改变一个变量，记录前后可重复证据。日志保留最少必要字段，公开前脱敏。共享访问日志可能泄漏目标域名、客户端 IP 和时间；TLS 不隐藏所有元数据。不要自动更换系统 DNS、修改防火墙、开启 TUN 或追加账户登录尝试。

若 SSH 或代理连通性恶化，停止增加变更，使用预先验证的恢复入口。timer 只在 Linux 主机保持运行且 systemd 正常时有效，不覆盖主机断电、重启后 transient timer 消失、主机被封或系统路由/防火墙错误。
