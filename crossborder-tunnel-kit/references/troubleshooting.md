# 故障索引：先定位，再改配置

新手先告诉 Agent：“在哪一步失败、客户端名称和版本、脱敏错误提示”。不提交真实 YAML、地址、密码、私钥或未脱敏日志。Agent 从现象选择下表；每次只改一个变量。

| 编号／现象 | 先看什么 | 对应处理与入口 | 如何确认／回退 |
|---|---|---|---|
| F01：YAML 无法导入、未知字段 | 是否导入个人文件而非模板，客户端是否为兼容 Mihomo，GUI 是否改写字段 | [导入指南](client-import.md)；[输入与渲染](inputs.md)；原生配置检查 | 原生检查与 GUI 均接受，不覆盖旧文件；失败切回旧配置 |
| F02：无法连接 VPS／握手失败 | 端口协议、时间、证书/SNI、UDP可达、服务监听、安全组 | [部署准备](deployment.md) 与 [验收](verification.md)；已确认 UDP 不通才评估 Reality | 实际握手与错误证书拒绝均测试；不可用时走控制台恢复 |
| F03：Hy2 通但 YouTube 视频失败 | 同账号／应用／样本的对照、出口、HTTP错误、地区/版权/账号因素 | [客户端 WARP-over-Hy2](client-warp.md)；[案例边界](field-lessons.md) | 普通视频/MV/直播三项复测；不以一个失败视频定性“IP被封” |
| F04：其他站点正常，Google无网络 | 应用及代理 DNS 答案、查询路径、节点域名的引导解析 | [链式 DNS 方案](client-warp.md)，核对 DoH 经 HY2，检查应用是否绕开 | 真实连接目标与可信解析相符；不要只改系统 DNS，不同时改服务器网络 |
| F05：页面能开但验证码频繁／登录异常 | 视频、登录、静态资源/API是否走不同出口；缓存、账号或地区提示 | 模板 GOOGLE 组统一相关域名；[会话一致性经验](field-lessons.md) | 查看不同域名实际节点与出口；整组回退，不只改 youtube.com |
| F06：小包通但视频/TLS卡住 | 丢包、RTT、路径MTU、负载、并发；比较不套 WARP 的基线 | [WARP_MTU 输入](inputs.md)，一次对照一个 MTU；保留原值 | 相同样本和时段复测，MTU 改动无收益即恢复 |
| F07：QUIC／UDP异常 | 规则匹配顺序、应用是否回退TCP、承载端口 | [QUIC 测试边界](client-warp.md)；不默认封UDP/443 | 临时规则生效且实际走TCP才算验证；测试后撤销不必要规则 |
| F08：WARP握手失败或出口仍被限制 | profile 是否有效配套、Endpoint、UDP承载、规则是否命中、出口是否真变 | [链式失败与回退](client-warp.md)；无资料停止；有限测试其他获授权出口 | 切回旧 YAML／整组 HY2；不对内置 WireGuard 运行 warp-cli 当作换出口 |
| F09：国内绕远或其他站点走错 | 规则顺序、全局模式、GUI覆写、客户端预解析 | [部署说明](deployment.md)；默认模板不含完整国内分流，按需求审阅合并 | 连接记录证明命中；恢复原规则，不能凭“已导入”宣称国内直连 |
| F10：IP查询与视频结果矛盾 | 查询域名与视频是否走同一路线，IPv4/IPv6是否混用 | [出口验证步骤](client-warp.md)；查询本身需指向待测节点 | 保留路径证据；一次查询不能代表整机或所有应用 |
| F11：切备线也失败 | 是否同一VPS/IP/供应商、TCP可达、Reality密钥和short-id | [可选路线](optional-routes.md) | 同机双协议没有主机级容灾；恢复已验收主线 |
| F12：变更后SSH失联／恢复不生效 | 本次变更清单、控制台、timer状态、是否重启过 | 停止增加变更，按 [恢复手册](rollback.md) 人工接管 | timer仅覆盖指定配置/服务，不覆盖路由、防火墙、断电或重启后丢失 |

## 给 Agent 的执行规则

先收集最少证据，区分假设与确认事实。日志可能泄漏域名、客户端地址和时间，只在私密目录保存；公开仅写错误类别和脱敏结论。不自动改 DNS、TUN、防火墙、账号或付费资源。

YouTube 播放还可能受浏览器扩展、缓存、地区授权、账号和服务自身故障影响，可参考 [YouTube 官方错误排查](https://support.google.com/youtube/answer/3037019?hl=en)。本表帮助缩小范围，不把数据中心 IP 或单一错误文本当作唯一根因。

排障结束交付：命中的编号、证据、改动、前后结果、回退方法及未解决项。模板和渲染器不会自行诊断或自动修复上述所有故障。
