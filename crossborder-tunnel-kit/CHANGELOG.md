# Changelog

## v0.5.0 — 2026-11-14

- 新增可选 cn-direct 路由：国内域名/IP/LAN直连、国内 DNS 分流和国内 UDP 放行；海外节点认证及 TLS 不变。
- 规则数据使用操作者审阅的本地文件与 SHA-256 固定校验，内嵌交付配置；不在 MIT 发布包内打包第三方规则数据。
- 巡检增加有限性能样本、health/quality 区分和脱敏错误分类；独立内核维护说明避免客户端自动升级破坏巡检固定哈希。
- 补充订阅与离线 YAML 的生命周期、客户端扩展规则保留、既有长连接重连验收及现场成功经验和局限。
- 保留 v0.4.0 无自有域名默认流程、旧渲染接口、受限发布及回滚、48小时巡检与异常5分钟复核机制。

## v0.4.0

默认无自有域名的 Hysteria2 直连与证书 SHA-256 固定校验；可选域名/CDN、双入口回退、私密订阅和入口维护。历史验证详见 references/versions.json。
