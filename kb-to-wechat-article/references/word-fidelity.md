# 复杂 Word 也能继续：先选保留方式，再交到草稿箱

如果你已经花时间做好 Word 排版，AI 不应只说“不支持”。它应告诉你卡在哪里，再带你走适合的一条路。

## 先用一句话选路线

> 你更希望“文字以后还可以修改”，还是“尽量保持现在看到的版面”？普通文字可走可编辑路线；复杂版面建议转成高清页面图片。图片可以放入公众号，但里面的字不能单独修改、复制或搜索，手机上也可能需要放大。你选哪一种？

已有明确偏好就沿用。图片方案必须获得用户对交付形式的选择，不能静默降级。若要求全部可编辑且与任意 Word 完全相同，要说明本包无法保证两者同时成立，协助选择关键保留项，不承诺万能转换器。

## 从 Word 到高清页面图片

全部本地操作，不必上传文稿到在线转换网站。AI 先展示用户自己的实际保存位置，下列名称只是示例。

1. **保留 Word 原件。** 另存用于发表的副本。修订稿先确认哪些修改要接受或拒绝，批注是否公开由你决定；“无标记”可能只是隐藏，不能当作清理完成。
2. **在 Word 中检查显示。** 看表格是否完整、公式是否正确、图有无错位、字体是否正常。缺字体优先回原电脑导出；替换字体须先确认外观变化。
3. **导出 PDF。** Windows Word 通常是“文件 → 导出 → 创建 PDF/XPS”，也可“另存为 → PDF”。选“标准”质量，选项中确认“文档”还是“显示标记的文档”。公开文章通常用已确认的最终正文，AI 不能替你接受修订或删批注。不同版本名称以页面为准。
4. **打开 PDF 核对。** 对照 Word 检查页数、表格、公式、图片、页眉页脚、修订及批注。错误先修正；可能遇到字体替换，不能跳过这一步。
5. **让 AI 整页转图。** 告诉 AI PDF 位置，并确认这是刚导出的已核对版本。AI 按 [工具说明](../tools/word-mode/README.md) 运行 `pdf-pages.py`，保留 `source.pdf`，生成编号 PNG、`article.html` 和 `manifest.json`。不是只提取内嵌图片；字、图、表格一起渲染。默认不裁页、不拼成长图、不套主题。
6. **核对交付。** AI 逐页查看页数、顺序、边缘、缺字和空白，再帮助你按手机宽度查看。Word→PDF、PDF→PNG、PNG→微信三处分别核对，不能用一次哈希检查代替。

提高分辨率只让放大后更清楚，不能把密集 A4 页面自动变得适合手机。正常宽度看不清时，经你同意在 Word 副本中改成单栏、加大字号、减小页面宽度再导出。也可交付“原版 PDF + 另做的手机版”，明确两份用途；不擅自裁掉页边、页码、列或表格。

## 把页面图片放进公众号草稿箱

这是 **人工或用户授权后由可用浏览器工具协助的路线**，不需要 AppSecret 或固定 IP。以下按钮名称是引导，未替用户完成后台实测；AI 每步查看当前页面再继续。

1. 打开 [微信公众平台](https://mp.weixin.qq.com/)，用有权限的管理员/运营者微信扫码登录。这是文章编辑后台，与找 AppID 的开发者平台不同。
2. 根据页面进入草稿或新建图文，填已确认标题。
3. 从正文图片入口选择本地上传，按 `page-0001.png`、`page-0002.png` 顺序插入。多选后仍核对顺序，不假设后台一定排序正确。`article.html` 仅为本地对照，里面的本地图片路径不代表已上传。
4. 对照清单检查漏页、重复、方向、裁切和上传失败；按后台当前要求配置封面，不把整篇多页稿当一张封面。
5. 用户决定是否发送手机预览。检查小字、宽表、清晰度和页间空白；微信压缩后看不清则回 Word 做手机版，不能称压缩也无损。
6. 保存为草稿，回草稿列表确认存在。**草稿不等于群发。** 结果不明确先查列表，避免重复创建；未经指令不发表。

## 遇到不同问题具体怎么办

| 现象 | 可以继续的处理 |
|---|---|
| 表格、公式、分栏、浮动图无法解析 | 选择 PDF 页图；需要可编辑时，另建手机版副本重建对应内容并逐项核对，未验收不称完成 |
| 有修订或批注 | 让用户确定最终正文或审阅版，在副本处理，导出后查看；不自动接受全部修订 |
| `.doc` 或扩展名不对 | 原 Word 另存真正的 `.docx`，不是改后缀；复杂版式直接导出 PDF |
| 断图或截图失败 | 核对原 Word/PDF，再检查本地图片和浏览器路径；修复后重新生成，不报成功 |
| PDF 加密或含交互表单 | 请所有者从原编辑器导出已确认的普通静态 PDF，不破解密码；表单填写内容先核对 |
| 页数、尺寸或图片超工具上限 | 原件保留；用户在编辑器按章节导出，记录页码并核对衔接，不静默丢页、降分辨率或截断 |
| 字体替换、公式异常 | 优先原电脑导出；同意后替换已有字体再导出，不擅自下载或分发商业字体 |
| 手机字小、宽表难看 | Word 副本改手机版；或同意后拆成有标题的多页并建立对应关系，不横向裁掉一部分 |
| 微信提示图片太大 | 以后台当前限制为准；保留原图，同意后压缩副本并手机复核，仍不可读则回原稿分章或调整版式 |
| 没有 Word | 询问是否已有能正确打开原稿的 WPS/LibreOffice，核对后导出 PDF；不同软件可能重排。也可请原作者导出，不擅自安装大型软件 |

## 原理与核查边界

HTML 不支持 Word 的全部排版功能，转换器可能依赖专有 CSS，不能推断微信保留。PDF 页图保留用户确认的视觉画面，不保留编辑语义、链接点击、辅助阅读结构，也不保证微信处理后每个像素不变。
