# 公众号连接卡住了？从打开网页开始

这份指南只在你选择“自动送进公众号草稿箱”时使用。**没有密钥、没有固定 IP，也可以照常写文章，再自己登录后台粘贴排版。** 不必为了试写先买服务器。

## 先分清两个入口

- [微信公众平台](https://mp.weixin.qq.com/)：查看你的公众号、编辑草稿和发表文章。
- [微信开发者平台](https://developers.weixin.qq.com/platform/)：查找所选公众号的开发标识、开发密钥和 API IP 白名单。

AI 给出可点击链接；有浏览工具时可在用户授权范围内打开并依据当前页面一步步指路。登录扫码、生成或重置秘密信息由用户本人完成；不要把密钥页面截图、录屏或全页读回聊天。没有浏览工具时就按下面顺序逐步指引，每完成一步再说下一步。

**菜单核对说明（2026-10-08）**：维护者现场确认的导航是首页左下方“前往使用” → 新页面左上角下拉按钮 → “公众号”。本版浏览工具对该站点有访问限制，未由工具重新点击验证；后续界面仍需以用户当前页面为准。设备厂商 H3C 的配置文档已使用“微信开发者平台 → 我的业务与服务 → 服务号 → 基础信息”，其中有开发密钥及 API IP 白名单。公众号类型、权限和平台更新可能让菜单名称不同。本版未登录用户后台逐项实测；看不到相同文字时，以当前官方页面为准，不能机械照点旧教程。[H3C 原厂配置说明](https://wwwsg.h3c.com/cn/d_202607/2886865_30005_0.htm)

## 一步步找到 AppID 与 AppSecret

1. **打开正确网页**：在浏览器地址栏输入 `https://developers.weixin.qq.com/platform/`。先检查域名，再用公众号管理员的微信扫码登录；不要打开陌生人提供的“密钥查询”网站。
2. **进入公众号功能并选账号**：如果先看到介绍页，点击页面左下方 **“前往使用”**；跳转后点击左上角的下拉按钮，在功能菜单中选择 **“公众号”**。若已进入此功能就不重复跳转。随后在“我的业务与服务”或当前账号列表中选择自己的公众号/服务号，核对名称。如果列表为空，先确认扫码者是否有该账号开发管理权限；请管理员协助，不新注册另一个号来代替。
3. **找到开发信息**：优先找“基础信息”；界面不同则找“开发接口管理/开发密钥”。AppID 一般标作“开发者 ID”，是账号标识。不要拿公众号原始 ID、小程序 AppID 或企业微信凭据代替。
4. **取得密钥**：找到 AppSecret（开发者密码/开发密钥）。已有受控保存的有效密钥就沿用。页面只给生成、启用或重置入口时，先检查这个号是否还连着其他工具；重置可能让它们失效，不能为了看一眼就点击。确需生成/重置时，由管理员本人完成验证，将新值直接保存到自己的密码管理器或受控秘密设置中。不要发给 AI，不放文章文件夹，不提交 GitHub。
5. **让脚本能使用**：按下面“私密填写”设置本次运行环境。AI 只检查变量是否存在，不能打印值。AppID 与 AppSecret 必须来自同一公众号。
6. **再配白名单**：在这个账号的“API IP 白名单”中添加实际执行脚本的出口 IP，保留其他正在使用的合法条目；保存和管理员确认由用户完成。不要照抄教程示例地址。

只是调用素材和草稿接口，不应为了完成本 Skill 而去开启接收消息的服务器回调、填写 Token/EncodingAESKey 或改自动回复；那是另一类功能。不要混用“网页授权域名”“JS 安全域名”和 API IP 白名单。

## 私密填写：以 Windows 一次性使用为例

优先使用宿主已有的秘密设置。如果没有，AI 可以指导用户打开 **开始菜单 → 搜索 PowerShell → 打开普通窗口**，将以下代码粘贴到窗口。随后出现的输入框由用户本人填写，AppSecret 使用隐藏输入；不要把真实值填进代码或发到聊天。

```powershell
$env:WECHAT_APP_ID = Read-Host '请输入这个公众号的 AppID'
$wechatSecretInput = Read-Host '请输入 AppSecret（输入时不显示）' -AsSecureString
$env:WECHAT_APP_SECRET = [System.Net.NetworkCredential]::new('', $wechatSecretInput).Password
Remove-Variable wechatSecretInput
```

AI 接下来应给出本机**已经替换完整路径**的连接检查命令，让用户在**同一个窗口**执行 `scripts/check_connection.py --approve-read`。Python 与脚本路径由 AI 核对并加引号，不让用户猜。“同一个窗口”很重要：这里只给当前窗口及其子程序设置变量，已经打开的 AI 应用不会自动获得这些值。后续上传命令也须在同一环境中运行；不能声称配置后所有应用都已连接。

使用完关闭这个窗口，或在其中执行 `Remove-Item Env:WECHAT_APP_ID, Env:WECHAT_APP_SECRET`。这不会写进本包或永久用户环境，但程序运行期间仍会在进程内使用明文凭据；它不是密码保险箱。其他系统让 AI 按实际宿主提供隐藏输入或秘密设置，不直接套用 PowerShell。

## 家里没有公网 IP，怎么办？

**没有独立公网地址，不等于无法访问微信。** 你在家打开网站时，路由器或运营商通常会替你通过一个公网出口访问。微信接口关心的是它看到的出口地址；局域网里的 `192.168.x.x`、`10.x.x.x` 或运营商内部地址不能直接拿来做这项配置。这是出站请求，不要求家里开放入站端口，也不需要内网穿透。

先让 AI 确认脚本究竟运行在你的电脑、云端 Agent 还是服务器。浏览器查到的地址可能与脚本不同；代理、VPN、容器和云端运行都会改变出口。AI 不得擅自关闭它们来“试试看”。本包检测到系统/环境代理时会停止联网，要求先明确网络方案；不自行绕过。网络层的 VPN 也需用户核对，不能仅凭环境变量检测就保证出口稳定。

### 路线 A：先用起来，暂不配置接口（最省事）

1. 让 AI 交付正文、配图及可用预览。
2. 自己打开 [微信公众平台](https://mp.weixin.qq.com/)，扫码登录目标公众号。
3. 按当前后台的“内容/草稿/新建图文”入口创建草稿，粘贴正文并上传图片。
4. 检查手机预览后自行发表。

这条人工路径不依赖本包的 API 白名单配置；后台仍可能要求正常的登录验证。AI 可以引导，不提取浏览器 Cookie 来代替正式 API。

### 路线 B：家宽出口偶尔变化，就更新当前白名单

1. 在**实际执行机器**上查当前公网出口。可让 AI 提供一个无需账号、只返回 IP 的 HTTPS 查询方式，并事先说明该服务会看到请求的来源 IP，不发送文章或密钥。分流网络中查询站点的出口仅供参考，须和微信实际请求路径核对；不要凭浏览器显示的 IP 一锤定音。
2. 返回开发者平台的目标账号 → API IP 白名单 → 编辑，加入核对过的当前出口，保留其他合法条目；完成平台要求的管理员验证。
3. 在同一运行环境执行一次连接检查。只获得访问令牌表示认证成功，不代表素材、草稿接口都可用。之后仅在用户批准下，用无敏感内容的短稿做一次草稿测试，再回后台检查。
4. 换 Wi-Fi、重拨、路由器重启或次日失败时，先看错误类别，确认是否 IP 变化。确有变化才更新白名单；不反复重置密钥、不自动反复上传。

若运营商多出口或地址频繁变化，白名单可能刚改好又失效。不要把整个运营商网段、所有地址或陌生代理 IP 都放进白名单；转路线 A 或 C。动态域名（DDNS）只帮助找到变化的地址，不会把实际请求的出口变成固定 IP，不能把域名当作白名单 IP 的替代品。

### 路线 C：经常自动运营，使用自己控制的固定出口

推荐思路是**只让负责送草稿的程序在固定出口的执行环境运行**，写作仍可在家中完成。可复用已有可信服务器；没有时再评估云服务器与保留的弹性公网 IP。若使用云函数/共享云端 Agent，不能假定出口固定，需要供应商明确支持固定出站 IP；较复杂的云网络可通过 NAT 网关绑定 EIP 实现。腾讯云官方说明了 [公网地址与 EIP](https://cloud.tencent.com/document/product/213/5224) 以及 [NAT 网关绑定 EIP](https://cloud.tencent.com/document/product/552/83056)。

用户选这条路线后，AI 才逐步协助：列清费用与维护责任 → 确认购买或复用 → 在执行环境安全配置密钥 → 核对实际固定出口 → 将该地址加入微信白名单 → 测试一次无敏感草稿并回验。新增远程环境会接触文章和密钥，需先说明数据流向。本包**不包含服务器部署、中转服务或密钥托管功能**；尚未配置时继续交付本地稿，不说“固定 IP 已解决”。保留地址通常有持续费用，释放或更换地址后要重新核对。

不默认推荐公共“免白名单中转站”。若用户选择第三方发布服务，应先核实服务方、官方授权范围、费用和退出方式；不能把 AppSecret、完整令牌和文章随便交给未知服务。稳定令牌也不能代替来源 IP 白名单。

## 常见卡点速查

| 看到的现象 | AI 应先带你检查 | 还能做什么 |
|---|---|---|
| 旧公众号后台没有“基本配置” | 进入微信开发者平台，核对账号与开发权限；以当前页面为准 | 继续本地写作 |
| 开发平台没有自己的账号 | 扫码身份和管理权限，不混用小程序/企业微信 | 请该号管理员协助 |
| AppSecret 看不到，只能重置 | 先找已受控保存的有效值，确认其他工具是否依赖 | 不擅自重置；暂用人工后台 |
| 提示 IP 不在白名单（如 40164） | 实际运行机器、实际出口、白名单保存状态 | 更正后检查一次；频繁变化选 A/C |
| 凭据错误/缺失 | 同一公众号的一对凭据、同一执行环境变量是否存在 | 不回显密钥，只报错误类别 |
| 能认证但不能建草稿 | 账号素材/草稿权限、请求内容与接口限制 | 保存稿件，人工放入后台 |
| 检测到代理或无法联网 | 向用户说明当前阻塞，请其确定受控网络方案 | 不改全局代理；先本地交稿 |
| 上传超时，不知道成功没 | 先查看后台与本篇收据 | 不重复新建，按推送指南续接 |

同一公众号还接了其他应用时，应由维护者统一协调令牌获取和密钥轮换；不要为排错频繁刷新令牌。错误码的精确定义和账号可用权限以微信当前官方文档为准。对外反馈只给脱敏错误类别、步骤与虚构示例，不上传原始响应、密钥、私人 IP 或未发表稿件。
