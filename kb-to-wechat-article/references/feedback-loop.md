# 可选：文章发表后的数据复盘

用户主动要求复盘、文章已经真实公开发表后才采集。草稿箱成功不代表已经发表。数据帮助提出下一次尝试，不能证明标题或封面单独造成某个结果。

## 两种可行方式

- 用户提供该篇文章的后台数据或脱敏截图；标明人工提供、统计日期和指标口径。
- 有对应 API 权限时使用本包 `tools/wechat_metrics_fetcher.py`；先读 `--help`，明确单篇真实文章 ID、时间区间和读取授权，再运行。凭据仅通过私有环境变量 `WECHAT_APP_ID`、`WECHAT_APP_SECRET` 提供，不写日志、不粘贴聊天。账号或接口不支持时退回前一种方式，或暂不复盘。

输出位于本篇 `feedback/`。原始接口返回可能含私人标题、标识或统计数据，应保持私有；不得作为开源示例或自动上传。

## 不混淆指标

只接受能精确匹配目标文章的数据。不拿账号总数、其他文章最大值或标题模糊匹配当作本篇统计；文章身份不明则报告阻塞。累计与每日指标分别解释，不重复累加累计数；无法获得的点赞、收藏、完读率等保留 null，不推算补齐。接口失败、区间限制和权限问题如实记录。

`tools/feedback_analyzer.py` 只对真实已有数据形成有限说明。样本不足时不下因果结论；可另由 Agent 结合选题、标题、结构及用户目标提出下一篇的实验建议，不能宣传为预测流量。

## 预约与内容积累

`tools/feedback_scheduler.py` 是本地到期清单工具，不是后台定时器，不会自动登录或收集数据。只有用户要求预约且宿主真正支持时才安排有限次数的 T+1h/24h/72h/7d 复盘，并记录回执；不默认补采全部历史文章。电脑或宿主未运行时不承诺执行。

用户工作目录内可按需要维护内容台账和经验摘要，保存真实来源及日期；这些记录不属于全局记忆更新，也不自动发到知识库。没有文件权限时在聊天里提供简短复盘，明确尚未保存。
