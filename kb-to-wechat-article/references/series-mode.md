# 系列文模式 (v4.1)

workflow-state 声明 series：series_id / series_total / series_index / series_palette（如 ["深夜蓝","深夜蓝紫","黎明金"]）。

1. 视觉一致性：封面构图语言系列统一（同族视觉隐喻）、色调弧按 palette 走、封面 prompt 注入系列约束不跳色；主题可不同但推荐理由说明与系列调性关系。
2. 内容衔接：互引不重复（姊妹篇已展开的方法只引用+一句话概括；写作前读姊妹篇大纲，去重清单入 revisions.md）；首篇埋线、中篇承接、末篇收口；文末可加系列导航。
3. 节奏调度：一篇文章一目录、共享 series_id 便于台账聚合；交付汇报「全家福」（系列进度+各篇主题/Media ID/时间一览）；content-ledger 系列条目、反馈按系列聚合分析。
4. 系列化判断：选题评估阶段主动评估系列化价值（素材量/话题纵深/读者连续收益）呈管理者定夺；管理者指定系列先出「系列规划」（总篇数/主题边界/色调弧提案）确认后逐篇执行。
