# 微信公众号写作助手

**把笔记、资料和想法，整理成一篇有依据、好读、方便你修改的公众号文章。**

不懂代码也可以使用：告诉 AI 你想写什么，它会带你选角度、列提纲、写初稿、检查事实和表达。第一次使用先带你走通一篇，不会一上来就让你填一堆配置。

**没有知识库、还没开通公众号，也可以开始。** 直接贴一段文字、提供文件，或讲清楚自己的想法即可。得到大脑等知识库连接是可选项，随时可以跳过、以后再接。

版本 **4.14.0** · 作者 **JoyZhang666** · [MIT 许可证](LICENSE)

## 你给什么，最后拿到什么？

- **你给**：一个主题或一份有权使用的资料，再说说写给谁看。
- **基本交付**：标题建议、提纲、文章草稿 `article.md`（无文件工具时直接在聊天中交稿），以及需要你核对的事实和来源。Markdown（`.md`）就是可用文本编辑器打开的文字文件，AI 会告诉你具体保存位置。
- **按需扩展**：封面与配图、排版预览；配置好公众号接口并批准后可送入草稿箱。进入草稿箱不等于公开发表，最后的发表按钮由你自己按。

## 第一次怎么开始？

先在支持 Skill 的 AI 助手中打开一个工作文件夹，把下面这句话发给它：

> 请从 https://github.com/JoyZhang666/joy-agent-skills 安装其中的 kb-to-wechat-article。先检查文件，再只安装这个 Skill，不覆盖已有版本、不安装可选工具。安装后带我一步步体验；知识库可以跳过，先不连接公众号。

如果 AI 不能访问 GitHub：打开仓库首页，点 **Code → Download ZIP**，解压后找到 `kb-to-wechat-article` 文件夹，将该文件夹的位置告诉 AI。不要把整个仓库当作一个 Skill 安装。

安装位置、连接失败怎么办、完整首篇体验都在 [新手引导](references/getting-started.md)。**引导在安装后的第一次对话中开始，不会在复制文件时偷偷运行程序。**

## 从想法到文章，只走这几步

1. **认识你的需求**：写给谁看、想说什么；已有答案就不再问。
2. **选择素材**：连接知识库，或者跳过并使用你提供的文字/文件。
3. **一起定方向**：先看标题和提纲，避免写完才发现方向不对。
4. **写作与检查**：整理正文，检查事实、引用、隐私和生硬套话；不编造你的经历。
5. **交到你手里**：给出草稿位置和修改建议。你满意后，再选是否配图、排版或送入公众号草稿箱。

例如可以说：

> 我第一次用，没有知识库。请用我下面三条心得写一篇给普通上班族看的短文，先给标题和提纲，不要发布。

也可以说：“连接我的得到大脑，只参考我选的笔记”“这份 Word 已定稿，请先检查能否保留原文排版”“继续修改上一版，不要重新推送”。

## 为什么值得试？

- **新手能跟上**：一次只解释当前要做的事，安装、连接和实际可用分开检查。
- **不被配置卡住**：知识库、图片工具和公众号接口都按需开启；不连接也能写。
- **有依据，保留你的表达**：记录素材出处，标出待核对内容，提供自然表达建议，避免把每个人写成同一种语气。
- **能接着改**：每篇文章独立保存；写到一半可以继续，后台改过的草稿先拉回再修改。
- **外发有边界**：知识库授权不代表允许公开所有笔记；发送草稿和创建定时任务另按用户指令执行。

## 需要准备什么？

| 想做到哪一步 | 所需条件 |
|---|---|
| 写出文字草稿 | 一个能读取 Skill 的 AI 助手，以及你愿意提供的主题或资料；无需 Python、知识库账号或公众号密钥 |
| 查知识库 | 对应服务账号及其官方连接方式；连接失败可跳过 |
| 使用本包检查脚本 | Python 3.10+；按脚本的依赖说明准备环境 |
| 排版预览 | 可用排版工具，如文颜 CLI；没有时仍可交付文字稿 |
| 送草稿箱 | Python 3.10+、Pillow、公众号接口权限与 IP 白名单；本包自动入口仅支持审核过的单图 HTML，详见[可选发布指南](references/push-governance.md) |
| 生成图片、截图或收集数据 | 对应可用工具和授权；可能产生服务费用，由用户选择 |

本包由提示词、规程、模板和辅助脚本组成，不是独立桌面软件。基础写作由 AI 执行；微信联调、图片生成及 Word 保真转换取决于当前工具能力。**公开版没有声称已经通过你的公众号或所有宿主的真实验收**；可选联网脚本先用测试草稿验证，不能一键保证完整发布流程。

## 密钥找不到，或家里 IP 总变化？

跟着 [公众号连接与家庭网络指南](references/wechat-account-and-network.md) 从打开官方网页开始，找到 AppID、私密填写 AppSecret，并核对 API 白名单。没有独立公网 IP 仍可能可用；偶尔变 IP 可更新白名单，经常变化可先人工交稿，长期自动化再选择固定出口。**不要求小白一开始购买服务器。**
