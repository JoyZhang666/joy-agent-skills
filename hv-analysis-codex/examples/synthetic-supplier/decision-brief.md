# 示例材料乙｜初次接触决策简报

> 完全虚构的教学示例。资料截止日：2026-10-01。未进行真实网页核验。

## 建议：先轻量接触，暂不形成代理或量产承诺

材料显示其业务方向与研究主题有关，可以通过一次初步访谈核实。但当前资料不足以确认乙公司的客户、质量能力和海外交付，不应从集团宣传跳到合作结论。

## 关键依据与限制

| 判断 | 依据 | 尚不能证明 |
|---|---|---|
| 乙与集团有关联 | 虚构信息卡 S2；D2 | 集团客户就是乙的直接客户 |
| 集团有营收及客户声明 | 宣传册 S1；D1 | 声明已经审计、乙拥有相同经营规模 |
| 转载不增加独立证据 | S3 明确引用 S1；D4 | 两个网址就构成两份独立确认 |
| 财务暂不可直接排名 | D1 与 D5 的实体、期间及币种不同 | 谁的经营规模更大或更优 |

## 合作吸引力与证据充分度

合作吸引力：产品方向有探索价值，具体技术匹配仍未知。  
证据充分度：不足以确认直接客户、认证、子公司财务或海外交付。缺资料不直接等同没有能力。

## 访谈与材料清单

1. 确认哪个法人主体签约、生产并承担质量责任。
2. 索取可披露的直接/间接供货关系及对应产品证明。
3. 核验认证的法人、范围、有效期和实际生产地点。
4. 获取匹配期间、币种和业务范围的财务或经营资料。
5. 核实海外交付记录、目标区域、支持能力和合作条件。

负责人和期限均待确认。若取得可信材料，再更新判断；如果关键资料无法提供，应继续保留缺口。

## 纵向、横向与交汇的续接

目前只能确认材料中给定的成立节点，不能编造发展历程。横向对比应先补同口径数据。交汇假设是“集团资源可能有助于乙的海外业务”，仍需要验证资源是否可实际调用；其他解释是乙承担加工职责，并不具有独立客户开发能力。
