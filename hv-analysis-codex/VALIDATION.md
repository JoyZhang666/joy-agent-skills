## 已验证

- **结构**：Codex skill-creator 的 quick_validate.py 通过；本地文件引用、名称、版本与安装说明已核对。
- **研究行为**：独立 Agent 只读取虚构材料和技能规程，在未读取示例答案、未联网的条件下，产出决策简报、证据表和 QA。结果没有继承母公司客户/营收，没有把转载当独立来源，也没有对不同期间/币种/范围直接排名。该结果是一个快速筛选场景的观察，不是普遍准确率。
- **工具回归**：19 项 unittest 通过，涵盖异构 summary、旧字段、原始 JSON/数值保留、计划缺失、重复 SQ/DP、错误输入、CSV 公式防护、不覆盖、危险图片/链接/原始 HTML 拒绝及本地素材白名单。
- **新手命令**：PowerShell 7 的 run.ps1 实际完成依赖检查与合成 SQ 汇总；4 个 URL、3 个声明的原始出处，均未被写成事实真实性或独立性已验证。
- **PDF**：Windows、已安装 Microsoft Edge、Markdown 3.11.1 与 Playwright 1.64.0；使用全新临时浏览器配置，启用 Chromium 浏览器沙箱、禁用网页脚本、离线上下文与请求拦截。合成简报、45 行长表格及一个本地 PNG 生成 5 页 A4 PDF，中文可提取、图片解码成功；逐页检查了中文、表格、分页及页码。发现并修正了相对文档链接被拒绝和标题落在页尾的问题。

测试复现（在此目录执行，需已有 Python）：

```powershell
python -B -m unittest discover -s tests -v
```

未安装可选 Markdown 时，PDF 输入限制用例会显示 skipped；这不能当作所有用例通过。可选 PDF 的真实渲染按 [安装指南](references/setup.md) 执行；unittest 本身不启动浏览器。

## 边界与未验证

- 本次工具执行使用已阅读和修订的代码、合成数据及专用测试目录；不是对未审代码的安全沙箱评测。首次在受限运行环境中启动浏览器失败，之后在获准的后台测试中完成；没有读取日常浏览器配置或账号。
- `.venv` 仅隔离依赖。浏览器安全设置和输入白名单不等于整个操作系统或所有浏览器后台流量已经隔离，也不保证恶意文档绝对安全；不应处理未审阅的不可信文件。
- 未做真实客户研究、真实网页事实核验、飞书/知识库联调、Linux/macOS 验收、大规模/长期研究或广泛对比评测；不宣称商业研究质量已被证明优于上游。
- 仅验证合成 PNG 解码，未覆盖所有图像编码、超长内容和复杂布局。报告中的“一页简报”指内容组织，转换器会增加封面并按长度分页，不保证物理单页。
- 生成、技术检查、研究事实 QA 和业务批准是不同状态；没有真实资料和实际批准时，不作已完成供应商资格或合作验收的结论。

真实运行材料和完整测试日志默认留在本地，不进入公开源码。反馈请使用虚构或脱敏内容。
