# 研究与商业尽调

本页提炼上游横纵分析框架及本机版的通用研究经验；不携带真实项目记录、个体关系或案例分数。

## 主体与边界

为研究对象记下法定名称、品牌/简称、官网、母子关系、业务范围和核验日期。候选无法排除时展示证据和选项，请用户确认；证据不足时不强行选择。人物研究先确认当前任职主体和角色，前任经历单独标记。

客户关系至少区分：公司自述客户、直接定点/供货、经中间供应商间接配套、项目历史关系与未核实关系。品牌名单和合作方 logo 不能单独证明直接供货。母公司的客户及认证不自动继承给子公司。

## 三条分析线

- **纵轴**：起源、人物与组织、关键转折、阶段、选择与约束、当前状态。用有依据的因果叙述连接事件；访谈自述的动机与研究者解释分开。
- **横轴**：先定义可比范围，再选直接竞争者、间接替代和潜在进入者。对齐期间、地域、币种、含税/不含税、集团/业务范围；不能对齐的数据分列并解释。
- **交汇**：每项主要判断列出支持事实、替代解释、反面证据、可验证信号。情景可以乐观/基准/不利，但不强制凑三个，不编造概率。

## 对象适配

| 对象 | 优先核验 | 决策含义 |
|---|---|---|
| 大型集团/一级供应商 | 控股结构、业务分部、客户/地域暴露、技术与产能 | 与集团还是具体业务单元合作；哪些资源真正可调用 |
| 民营/二级供应商 | 主体、产品性能、认证范围、量产证据、交付与财务材料 | 先接触还是先补材料；不能用招聘宣传代替财务核验 |
| 母子公司组合 | 各实体产品、资产、客户、认证与角色 | 哪个实体签约、生产、承担质量和出口责任 |
| 人物/技术团队 | 当前职位、任期、代表性成果及原始来源 | 区分当前职责、历史影响和推测，不扩展到私人生活 |

合作尽调可考察产品匹配、质量/量产、客户路径、交付能力、海外意愿、财务和合规材料。先列证据与缺口，再给范围明确的建议。若评分有用，说明权重、未知值和依据；合作吸引力与证据充分度分别呈现，不将缺材料直接等同低能力。

## QA、失败与更新

交付前核对主体、日期/单位、原文与结论、客户关系、来源独立性及主要反证。没有新闻不代表事件不存在，没有披露不代表数值为零。数量乘单价只有在数据、期间、产品范围和估算假设有依据时才有意义；否则保留未知。

搜索或协作者失败时检查实际保存的文件，区分缺文件、格式错误与事实缺口；使用已有可定位证据补缺，保留恢复记录。不要把缓存摘要、训练知识和猜出的 URL 伪装成已读来源。外部交付结果不明时先回读，不能盲目重发。

按需更新时保存新运行目录，记录事实的旧值/新值、时间口径、来源变化以及受到影响的结论。未重新查证的部分沿用旧日期标记，不包装成全新研究。
