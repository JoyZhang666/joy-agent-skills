# 变更前记录模板

只填写任务需要的项目。已有明确授权的范围不重复审批；未知项保留待确认，不预填为通过。

| 项目 | 待填写内容 |
|---|---|
| 目标 | 安装 / 只读诊断 / 切换节点 / 修改 TUN 等 |
| 主机与范围 | 本地记录即可，公开报告使用别名 |
| 当前版本 | 内核、架构、mihomo 与服务定义 |
| 端口冲突 | 监听进程与处理选择 |
| 凭据来源 | 私有配置位置的别名；不填写 URL、token、密码 |
| 变更差异 | 具体文件、字段、服务 |
| 影响 | 哪些应用会断流、是否需维护窗口 |
| 恢复 | 私有备份、恢复步骤、触发条件 |
| 验证 | API 回读、路由、DNS、目标业务 |
| 授权 | 已批准范围 / 尚缺的信息 |

不把诊断失败直接写成供应商故障；报告已观察事实与待验证假设。权限拒绝处理见[工具限制](hermes-terminal-restriction.md)。
